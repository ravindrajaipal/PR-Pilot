1. Project Title & Elevator Pitch

                
PR-Pilot — Multimodal Open-Source PR & Visual Bug Companion Powered by Gemma 4

                
An open-source AI maintainer copilot and reusable Agent Skill (`SKILL.md`) that combines Gemma 4's multimodal vision with Git AST diff analysis to correlate UI bug screenshots with exact lines of code, coach first-time Hacktoberfest contributors, block low-effort spam PRs, and synthesize Playwright regression tests.

              


              

                
2. How It Hits All 3 Prize Categories at SUIIT

                
    
                  
  • Best Use of Gemma 4: Uses Gemma 4 via the Gemini API to jointly inspect UI screenshots (including regional Odia script rendering on SUIIT's portal) and unified Git diffs in a single multimodal prompt.
    • 
                  
  • Best Open-Source AI Project (DigitalOcean): Ships both a standardized `SKILL.md` agent skill and a self-hostable Python model harness (`gemma4_harness.py`) + GitHub Action for open-source maintainers.
    • 
                  
  • Best Software Project & Overall Hackday Winner: Full interactive browser studio with visual bounding-box correlation, Hacktoberfest 2026 spam-shield scoring, and automated Playwright + WCAG 2.2 accessibility verification.
